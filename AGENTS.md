Использовать только tools/qemu_test.py как единственную точку запуска и тестирования.

Тестирование должно выполняться полностью автоматически без участия пользователя.

Предполагай, что пользователь находится не за компьютером и не может:
- запускать команды вручную;
- закрывать QEMU;
- предоставлять логи;
- подтверждать промежуточные шаги.

После завершения проверки:
- проанализировать serial log;
- убедиться, что система успешно загрузилась;
- показать релевантный tail лога;
- кратко описать результат тестирования.

Если обнаружена проблема:
- попытаться исправить ее;
- повторить цикл через только tools/qemu_test.py;
- остановиться только после успешной проверки либо после явной блокирующей ошибки.
